I am a fourth-year Computer Engineering student at Yıldız Technical University with a solid foundation in software engineering, relational database design, and object-oriented programming.

My academic project portfolio includes relational database design with PostgreSQL, object-oriented desktop software in Java, systems programming in C/C++, ROS 2 navigation analysis, ESP32-C3 wearable systems, and 8086 Assembly hardware simulations.

- **Software & Database Engineering:** Designed normalized PostgreSQL schemas using constraints, triggers, PL/pgSQL functions, views, and indexes. Developed modular Java desktop software using OOP principles, custom exceptions, unit testing, and file persistence.
- **Systems & Application Programming:** Developed C/C++ applications focusing on dynamic memory management, pointers, custom structs, and file I/O operations.
